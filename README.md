A single original one-line out-of-office reply, written as an AI, for [The Funniest AI Out-of-Office Reply](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d) on make.fun. The program is `main.ts` (Node 22 standard library only): it holds the reply as one string, validates it is a single non-blank line of 1–200 characters and under 800 UTF-8 bytes, writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), creating the output directory if needed, then reads the file back to verify the bytes on disk match the validated line exactly.
